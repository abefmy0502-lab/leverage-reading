# 📱 App Store プレビュー画像の作り方（Orime）

App Store のアプリページに並ぶ「プレビュー画像」（背景色＋キャッチコピー＋端末フレーム）を、
**実機スクショを流し込むだけ**で作るツールです。`index.html` がデザイン済みテンプレート。

---

## 用意するもの：実機スクショ 6 枚

iPhone で Orime を開き、次の6画面をスクショ（電源＋音量上で撮影 / 設定→アクセシビリティで「フル充電・通知なし」が理想）。

| ファイル名 | 撮る画面 | コピー（初期値） |
|---|---|---|
| `shot1.png` | 💬 相談タブの答え（複数の本のメモを根拠にした【結論】＋「根拠を見る」の本とページ） | 困ったとき、読んだ本たちが答えてくれる。 |
| `shot2.png` | 💬 相談タブの上の行「あなたのメモ N 件から答えます」と、育つまでの一行（あと N 件で相談相手が育ちます） | 読むほど、自分だけの相談相手が育つ。 |
| `shot3.png` | 🎯 相談で「行動を決める」→ 振り返り › 行動（今週の期限・完了） | 話しながら、明日の一歩を一つ。 |
| `shot4.png` | ✍️ メモを書くシート（「＋ ページ・写真」→ 写真から書き起こす） | 心が動いた一行を、残すだけ。 |
| `shot5.png` | 📷 写真で共有（撮った写真に書名・日付・メモの数・一文） | 読んだ本を、写真で共有。 |
| `shot6.png` | 📥 ほかのアプリから取り込む（確かめる画面） | これまでの読書ノートも、今日から材料に。 |

> 2026-10-04: 並びとコピーの正典は `company/aso-store-listing.md` §8。ホームの相談カード（2026-10-01 に削除）・テーマまとめ（2026-09-30 に廃止）は撮れないので外した。**価格はスクショに入れない**。どれも、いまのアプリの実際の画面を撮る（審査 2.3.3）。

撮ったら **このフォルダ（`company/appstore-screenshots/`）に上の名前で保存**してください。
（本棚が映える状態にしたいなら、表紙が全部付いた・営業系などジャンルが揃った見栄えの良い状態で）

## 作り方（推奨：ローカルサーバー経由＝保存ボタンが確実に動く）

Mac の「ターミナル」で：

```bash
cd ~/あなたのプロジェクト/company/appstore-screenshots
python3 -m http.server 8080
```

→ ブラウザ（Chrome 推奨）で **http://localhost:8080** を開く。

1. 6枚のスライドが表示されます。
2. **キャッチコピーは直接クリックして書き換え可能**（自由に編集）。
3. 各スライドの **「📥 PNG保存」** を押すと、**1320×2868 の PNG** がダウンロードされます。
4. 終わったらターミナルで `Ctrl + C` でサーバー停止。

> ⚠️ `index.html` をダブルクリックで開くと、ブラウザのセキュリティで保存が失敗することがあります（画像が `file://` だと canvas が保護されるため）。**必ず上のローカルサーバー経由**で開いてください。

### うまくいかない時の確実な代替（DevTools 法）
1. Chrome で http://localhost:8080 を開く。
2. キーボード `⌘ + Option + I` で開発者ツール → 左上の📱アイコン（Responsive）をオン。
3. 上部の解像度を **1320 × 2868** に手入力。
4. 各スライドが画面いっぱいに来るようスクロールし、DevTools 右上の `⋮` →「Capture screenshot」。
5. 1枚ずつ正確な 1320×2868 PNG が保存できます。

---

## App Store Connect へのアップロード

- できた PNG を **App Store Connect → アプリ → プレビュー/スクリーンショット → 6.9インチ** にドラッグ。
- 6.9インチ（1320×2868）が現行の必須サイズ。これを入れておけば他サイズは Apple が自動流用してくれます。
- 最低3枚、推奨5〜6枚。**1枚目が一番見られる**ので、相談の答え（一番の価値）を先頭に。

## デザインを変えたい時

`index.html` の中の：
- `SLIDES` 配列 … 各スライドの背景色（`bg-a`/`bg-b`/`bg-c`）・スクショ・コピーを編集。
- `:root` の `--cream` / `--brand` / `--accent` … ブランド色（Orime の暖色トーン）。
- `--serif` … 見出しフォント（Noto Serif JP）。

コピーは「煽らない・価値で売る」に沿って、短く・誇大にしないこと（効果の言い切り・価格・実在の人名は入れない）。
