## 0. エグゼクティブサマリー（結論ファースト）
- **KGI**：2026年中＝月次純利益10万円（**継続課金 約150人**）／2027年中＝月30万（約430人）／ストレッチ＝月100万（約1,400人）。
- **最大の壁**：「無料体験ゼロ・初日¥990」で**継続150人**を作ること。逆算で**数十万リーチ→3万ストア訪問→7千install→350課金→150継続**が必要（オーガニック6ヶ月では挑戦的）。
- **外部2コンサルの相違を統合した中心戦略**＝**「7日間トライアル ＋ 年額プラン」**：
  - 年額（グロース#1レバー）：12ヶ月リテンション33.9% vs 月額13.8%（約2.4倍）。"同時150人維持"より"年額契約を積む"方が遥かに楽。
  - 7日トライアル（ASO#1レバー）：ストア表示が「無料DL＋App内課金」になり**発見性・install数が桁違い**。恒久無料化（フリーミアム）はしない＝経済性は維持。トライアル中のAI原価は**実装済みメータリングで防御**。
- **フリーミアム（恒久無料枠）はやらない**（両コンサル一致：コンバージョン1/5・AI原価だけ増える最悪手）。

## 1. KGI ユニットエコノミクス（再掲）
- 価格 月¥990（税込）／App決済15%（Small Business）→ **1課金者の手残り ≈ ¥700/月**。
- 固定費 ~¥7,000/月込みで **2026 KGI ≈ 継続150人**。
- 年額案 **¥7,800〜8,800/年**（実質2〜3ヶ月オフ）→ 前払いLTV増・チャーンの谷を構造的に解消。

## 2. ファネル現実解（150継続の逆算 / コンサル試算）
| 段階 | 現実レンジ | 150継続に必要な規模 |
|---|---|---|
| 認知・リーチ | — | 十数万〜数十万 |
| ストア訪問→install | 20〜30%（日本は低め） | 訪問 約24,000〜32,000 |
| install→課金（ハードペイウォール） | 3〜7% | install 約6,000〜8,000 |
| 累計課金（初期チャーン込み） | — | 約300〜400 |
| 月次チャーン | 月12〜14%（年額で大幅改善） | 同時継続 150 |
> トライアル導入時：install→トライアルが上がり、長めのトライアル→課金は30〜42%。**install母数と発見性が増える＝この逆算が一気に楽になる**。

## 3. 戦略レバー（効く順）
1. **年額プラン導入**（KGI到達確率を最も上げる）。月額は「お試し的に高い」見せ方で年額へ誘導。
2. **7日間無料トライアル導入**（発見性＋install増。AI原価はメータリングで防御）。←要・元帥判断
3. **ペイウォール手前で"瞬間価値"を見せる**：想起カードのサンプル／マイ読書脳のデモ。install→課金を3%→6%へ（"想起"は使って効く＝初日課金と最も相性が悪い＝最大リスクをここで潰す）。
4. **ASO＋日本語最適化**（install の70〜80%がオーガニック）：
   - アプリ名にKW同居：例「**Orime：読書記録・読書メモ・AI選書**」（Orime単体は検索されない）。
   - サブタイトル「読みっぱなしを防ぐ振り返り読書術」。KWフィールドは名前と重複させない。
   - スクショ1枚目＝**ランダム想起／マイ読書脳**（競合に無い差別化）。文字焼き込み。
   - プライマリカテゴリ＝**仕事効率化（Productivity）**推奨／セカンダリ＝ブック。
5. **X build in public ＋ Note SEO**（`marketing-playbook.md`／`marketing-week1-kit.md`）：CACゼロの2本柱。
6. **課金後オンボーディング完走＋想起リマインド通知**：初月チャーンを潰す最重要リテンション施策。

## 4. 差別化メッセージ（営業/ストア/LPで統一）
- **「SNSではない、自分のための読書アプリ」**（読書メーターの通知疲れ層を直撃）。
- **「記録して終わり、を終わらせる」**（競合は記録止まり・Orimeは想起/活用）。
- **「自分のメモが答えになるAI（マイ読書脳）」**（唯一無二）。
- ターゲットを**ビジネス書・学習目的の読書家（ニッチで深い層）**に絞る。万人向けに二強と戦わない。
