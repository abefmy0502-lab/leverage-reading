# 🛡 Orime ブランドガードレール 5か条

> 2026-07-11 制定（レッドチーム・ブランド整合監査より）。全ての発信（X / note / DM / ストア文言）はこの5か条を通過してから公開する。詳細な却下事例は `sales-playbook-owner.md` 付録参照。

1. **実数原則** — 自分について語る数字は、読書記録・Git履歴・ダッシュボードで立証できるものだけ使う。立証できなければその投稿・タイトルは出さない（「3日で9割忘れる」等の疑似統計も禁止。半端な実数は丸めた嘘より強い）。
2. **提供開示原則** — コード・特典を提供した相手には「#提供」等の明記を**こちらから**依頼する（景表法ステマ規制対応）。提供の事実を隠した紹介は受けない。
3. **氏名・引用の明示許諾** — 著名人・ユーザーの氏名やコメントは、本人の明示許諾メッセージが手元にない限り公開物に載せない。例外なし。それまでは匿名化（「ある経営者」等）。
4. **解約者への接触規律** — 情報提供は1通まで。損失フレーミングを先頭に置かない。割引で縋らない。
5. **テンプレは下書き専用** — リプ・DM のテンプレ型文は、相手固有の一文を足すまで送信禁止。固有の内容に触れられないなら送らない（0件でよい）。
