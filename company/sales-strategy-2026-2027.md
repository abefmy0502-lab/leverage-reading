## 0. 結論（1枚）

- **2026年12月: 月次粗利10万円 = 継続課金 約100人**（手残り≈¥1,000/人/月）
- **2027年12月: 月次粗利100万円 = 継続課金 約1,000人**。ただし週6.5hの個人稼働では到達不能 → **2027年は粗利の30%を再投資して「時間を買う」年**（外注・自動化・プロダクト内バイラル）
- 戦い方: **①noteでSEO資産を作る（複利・休日）②Xで毎日温める（信頼・平日30分）③プロダクト自身に売らせる（共有カード/ASO/年額）**
- 一言方針: 「フォロワー集め」ではなく「**検索されている痛みに、資産になる記事で答え、アプリで解決する**」。宣伝1:価値9・誠実さがブランド（AIっぽい量産は最大の敵）

## 1. ユニットエコノミクス（逆算の土台）

| 項目 | 値 | 根拠 |
|---|---|---|
| 価格 | App 月¥1,480 / 年¥12,800 | `src/lib/billing.js`（真実はストア） |
| 手残り/人/月 | **≈¥1,000**（保守値） | 月額: 1,480×0.85−AI原価≈¥1,210 / 年額: 12,800×0.85÷12≈¥907 のブレンド |

## 2. チャネル戦略（何を・なぜ・どれだけ）

### 主戦場は2つ＋土台1つ（週6.5hに収まる最小構成）

| チャネル | 役割 | 時間 | 複利性 |
|---|---|---|---|
| **note** | SEO資産＝「痛み検索」の受け皿。24時間働く営業マン | 休日2h×1（執筆） | ◎ 記事は消えない |
| **X** | 信頼と再訪。founder-led・build in public | 平日30分 | △ 流れるがプロフに蓄積 |
| **ASO**（App Store最適化） | 検索「読書 メモ」等からの自然流入 | 月1回30分の見直し | ◎ 設定は複利 |

### プロダクト自身に売らせる（稼働ゼロの営業マン・実装済み）
- **🖼 引用カード共有**（Orimeワードマーク入り画像）— ユーザーの共有1枚が広告
- **LP**（leverage-reading.vercel.app）— note/X の全リンクの着地点
- **年額プラン主役のペイウォール** — チャーン構造の解決
- **想起プッシュ** — 解約抑止（使わない月も価値が届く）

### やらないこと（時間の防衛線）
- ❌ Instagram/TikTokの**手動**運用（2027に外注で参入）
- ❌ 毎日のnote投稿・無理な相互フォロー・スペース登壇
- ❌ 広告出稿（2026年は0円。2027年にLTV確定後、CAC<LTV/3でのみ）
- ❌ フリーミアム化・値下げ（kgi-roadmap全社会議の結論を維持）

## 3. 週間運用システム（これが本体・カレンダーに登録する）

**合計: 平日30分×5 + 休日120分×2 = 週6.5時間**

### 平日（毎朝30分・時間帯固定を推奨）
| 分 | やること | 具体 |
|---|---|---|
| 0–5 | 当日ポスト投下 | 日曜に作り置きした予約投稿の確認（または手動投下） |
| 5–20 | **検索リプ営業** | Xで「読書 忘れる」「積読」「読書メモ」「本 身につかない」を検索 → 悩んでいる生の投稿に**宣伝なしの価値リプ**を3件。プロフィール導線で回収する |
| 20–30 | 回収と記録 | 通知/DM返信・App Storeレビュー返信・`操縦席`の数字を一目（メモ1行） |

### 土曜（120分）: note執筆
- `note/editorial-calendar.md` の当週テーマを1本書く（60〜90分）
- 残り時間で見出し画像（Canvaテンプレ使い回し）と記事末CTA（1回だけ・やわらかく）
- **時短の武器**: リポジトリの note チーム（`/note-kikaku`→`/note-kosei`→`/note-shippitsu`→`/note-hanbai`）にドラフトを作らせ、**自分の声に書き直す**（AI臭のまま出さない — ブランドの生命線）

### 日曜（120分）: 仕込みとレビュー
| 分 | やること |
|---|---|
| 0–60 | X投稿を7本作り置き→予約（§4の柱ローテ。note記事の切り出しで2本は埋まる） |
| 60–80 | note公開＋X告知ポスト（固定ポスト更新） |
| 80–100 | **週次レビュー**: 操縦席で「新規課金/インストール/LPクリック/note PV/Xプロフクリック」を記録 → §6のif-thenに1つでも該当したら翌週の計画を差し替え |
| 100–120 | 予備（ユーザーの声への返信・許可取り→LPの「声」枠へ還流） |

> **原則: 稼働を増やさない。数字が悪い時は「量を増やす」のではなく「型を変える」（§6）。**

## 4. コンテンツ戦略

### X（柱は5つ・日替わりローテ / marketing-playbook §3 準拠）
1. **実体験・本音**（読書の失敗談・今読んでる本）→ 人間味
2. **読みっぱなし防止Tips**（想起・1冊から行動を出す方法）→ 保存される
3. **build in public**（数字公開・ユーザーの声・開発の裏側）→ 応援者化
4. **本の学び＋自分の解釈**（引用→「自分はこう使う」）→ 拡散されやすい
5. **Orimeの画面1枚**（週1まで。あくまで価値の実演として）

**型テンプレ**（作り置きを速くする）:
- 悩み共感型: 「◯◯、ありますよね。実は原因は△△じゃなくて□□。私は〜で解決しました」
- リスト型: 「読んだ本を無駄にしない3つの習慣: 1… 2… 3…」
- ビフォーアフター型: 「昔: 月4冊読んで何も残らない → 今: 月2冊で行動が3つ変わる。差は◯◯」

### note（週1本・日曜公開 / editorial-calendar 準拠）
- **SEO記事**（月2本）: 「本 読んでも忘れる 対策」「読書メモ アプリ 比較」「積読 解消」等の高インテント検索。**比較記事が最も課金に近い**
- **ストーリー記事**（月1本）: 開発記・数字公開（「個人開発、今月の課金者は◯人でした」）
- **思想記事**（月1本）: レバレッジ・リーディングの現代的実践
- 記事末CTA固定文: 「この仕組みをアプリにしたのが Orime です。読みっぱなしを、やめる。→（リンク）」

### 収益の第二の柱（2026 Q4 に1回だけ）
- **有料note 1本**（¥980買い切り）: 「読書を成果に変える完全ガイド」— 無料記事12本の集大成。月1〜3万の補完収益＋Orimeへの最強導線。**主役はあくまでサブスク**なのでこれ以上増やさない

## 6. 判断ルール（if-then・私が居なくても迷わないため）

| 観測（週次レビューで確認） | 行動 |
|---|---|
| note記事→LPクリック率 < 2% が2本連続 | CTAを記事末→中間に追加・文言を「悩み文脈」に書き換え |
| note月間PVが2ヶ月連続で横ばい | SEO記事のキーワードを再選定（検索ボリュームのある悩み語へ）。`/note-shijo` で競合調査 |
| Xポストの保存数ゼロが1週間 | 柱②（Tips）の比率を上げ、型をリスト型に寄せる |
| install→課金 < 3% が1ヶ月 | ペイウォール手前の価値プレビュー改善 → それでも低ければ**7日間無料（Introductory Offer）のABを検討**（kgi-roadmap「データ根拠でのみ再検討」に合致） |
| 月次チャーン > 12% が2ヶ月 | 獲得を止めてでも継続体験（想起・初週オンボ）を改善（穴の空いたバケツに水を注がない） |
| 新規課金が月次目標の50%未満 | 翌月は比較記事（最も課金に近い）を2本に増やし、ストーリー記事を休む |
| ある記事が10,000PV超え | 翌週に同テーマの続編＋X固定ポスト差し替え |
| 稼働が週6.5hを超え始めた | **何かを増やしたなら何かを止める**。このルール自体が最優先 |
