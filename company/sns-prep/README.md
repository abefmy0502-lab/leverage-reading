## 動画（縦 1080×1920・字幕つき・画面の下に「画面は見本です。…」）
- `npm run demo` → `npm run mkt:record -- shelf-scan goal-roadmap consult-answer focus-mode` で作り直せる（台本は `scripts/marketing/scenarios.mjs`）。出力は `marketing-out/videos/<日付>/<名前>/final.mp4`（git 管理外）。
- 2026-11-22 に撮った 4 本（題はビフォー ↓ アフター・最後の字幕は「無料プランで、今日から試せます」）: 本棚の写真からまとめて追加（18 秒・7 冊を読み取る）・目標とロードマップ（24 秒）・相談（27 秒）・集中モード（15 分のタイマー・23 秒）。
- 本棚の写真は仮の写真（机の上の本）で撮った。オーナーの本棚の写真を `scripts/fixtures/` に置いて差し替えると伝わりやすい。

## 声（ナレーション）を入れる（2026-11-22 オーナー「落ち着いた男性の声で」）
- 動画を作ったあと、Mac のターミナルで（鍵はその場のシェルで渡す・ファイルに書かない）:
  `OPENAI_API_KEY=（鍵） npm run mkt:voice -- marketing-out/videos/<日付>`
  → 各フォルダに `final-voice.mp4`（映像はそのまま・字幕と同じ文を同じ時刻に読む・画面の動画は最初に題も読む）。
- 声は OpenAI の読み上げ（`onyx`＝低く落ち着いた男性）。替えるなら `MKT_VOICE=ash`。話し方は `MKT_VOICE_STYLE` で指示できる。
- 鍵が無いときの試し: `npm run mkt:voice -- <フォルダ> --engine say`（Mac の声・機械っぽい）。
- 声が次の字幕にかかると「⚠」が出る。そのときは台本の `hold` を足すか、字幕を短くする。
- 費用の目安: 1 本 30 秒で 1 円未満。
