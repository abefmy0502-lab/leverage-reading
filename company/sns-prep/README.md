## 声（ナレーション）を入れる（2026-11-22 オーナー「落ち着いた男性の声で」）
- 鍵は Mac のキーチェーンに入れる: **`npm run mkt:key`**（1 回貼る → 空白や見えない文字を取り除く → OpenAI で通るか試す → 通ったときだけ保存・鍵の文字は出さない）。`security … -w` で 2 回貼る入れ方は、見えないまま間違えて 401 になった（2026-11-22）。
- Mac で初めてのときだけ: `node node_modules/playwright-core/cli.js install chromium ffmpeg`（録画用のブラウザと部品。Google Chrome だと台本によって録画が空になった）。
- 鍵なしで試すなら `npm run mkt:videos -- --say`（Mac の日本語の男性の声 Reed）。
- **いちばん簡単: `npm run mkt:videos`**（声を作る → お試しモードを起動して撮る → 概念の動画 → 声を重ねる、まで 1 回で。できあがりは `marketing-out/videos/<今日>/<名前>/final-voice.mp4`）。
- 手で 1 つずつやるときの順番（声に合わせて間を取るため、**先に声を作ってから撮る**）:
  1. `npm run mkt:voice -- --prepare`（台本の文を 1 つずつ声にして、長さを覚える・`marketing-out/voice-cache/`）
  2. `npm run demo` を別のターミナルで → `npm run mkt:record -- shelf-scan goal-roadmap consult-answer focus-mode` と `npm run mkt:explainer -- concept-consult concept-goal concept-focus`（声の長さに合わせて間を取る）
  3. `npm run mkt:voice -- marketing-out/videos/<日付>`（作り置きの声を重ねる）
  → 各フォルダに `final-voice.mp4`（映像はそのまま・字幕と同じ文を同じ時刻に読む・画面の動画は最初に題も読む）。
- 声は OpenAI の読み上げ（`onyx`＝低く落ち着いた男性）を **1.25 倍速**（2026-11-22 オーナー「遅い」・`MKT_VOICE_SPEED` で変えられる・元の声は作り置きのまま速さだけ変える＝頼み直さない）。替えるなら `MKT_VOICE=ash`。話し方は `MKT_VOICE_STYLE` で指示できる。
- 鍵が無いときの試し: `npm run mkt:voice -- <フォルダ> --engine say`（Mac の声・機械っぽい）。
- 声が次の字幕にかかると「⚠」が出る。そのときは台本の `hold` を足すか、字幕を短くする。
- 費用の目安: 1 本 30 秒で 1 円未満。

## 動画の決まり（仕組みで守る・2026-11-22 オーナー）
- **初めて知る人にも分かる順**: 困っていること → Orime とは何か（どの動画も同じ一言「Orime は、読んだ本のメモから答えてくれる読書アプリ」）→ 使い方 → 「これからは、…」→「無料プランで、今日から試せます」。アプリの中の言葉（行動リスト・根拠・ロードマップ・区切り …）は使わない（`scripts/marketing/clarity.mjs`・テストで確かめる）。
- **冒頭は困っていること**: 1 行と、大きな線のイラスト 1 枚（`explainer/art.mjs` の `problem…`）。画面の動画は台本の `problem` と `intro: true` の段の間、画面を出さずに絵だけ。
- **縦いっぱいに使わない**: 字・絵・画面は安全な範囲（上 250・下 1440・左 60・右 960＝`scripts/marketing/safeZone.mjs`）の中だけ。SNS の上の名前・下の説明文・右のボタンに重ねない。
- **はみ出し・重なりは書き出さない**: 書き出す前に、見えている字と絵の位置を確かめ、範囲の外・重なりがあれば「✗ 配置を直してください」で止まる。横に長い字は収まるまで自動で小さくする。
- **変な所で改行しない**: 「1 日 15 分」の数と単位の間では割らない。割るのは文節の切れ目と「、」「。」の後だけ。
- **読み違えない**: 声には、読みを決めたかなを渡す（`scripts/marketing/readings.mjs`＝1 日＝いちにち・1 分＝いっぷん・① ＝ひとつめ・積読＝つんどく・何から＝なにから …）。読みが決まっていない数字が台本に入ると、テストも声づくりも止まる → `readings.mjs` の COUNTERS か WORDS に 1 行足す。声づくりのたびに `marketing-out/voice-cache/readings.txt` に「字幕 → 読み」の一覧が出るので、気になる読みはそこで確かめる。
