## 1. 12 月「今年の読書をふり返る」

### 参照名（App Store Connect の中だけ・64 字まで）
```
2026-12 今年の読書をふり返る
```

### イベント名（30 字まで・10 字）
```
今年の読書をふり返る
```

### 短い説明（50 字まで・27 字）
```
今年読み終えた本と、いちばん残した一文を1枚の画像に。
```

### 長い説明（120 字まで・78 字）
```
12月は「写真で共有」に「今年」が加わります。今年読み終えた冊数、メモ、実行した行動と、いちばん残した一文を1枚の画像に。読み終えた本が1冊あれば作れます。
```

### 設定
- **バッジ：Special Event**。正直に選んだ理由：12 月にだけアプリの中に「今年」が出る、年の終わりの行事。Challenge（期限までに目標を達成する）は、アプリに達成・順位の仕組みが無いので使わない（反ゲーミフィケーション）。Major Update・Premiere・New Season は、新しい機能でも新しい中身でもないので使わない。
- **期間**：2026-12-01 0:00 〜 2026-12-31 23:59（日本時間・31 日＝上限の 31 日ちょうど）。アプリの「今年」も端末の日付が 12 月のあいだだけ（`isYearWrapSeason`）なので、イベントの期間と合う。
- **宣伝の開始**：上限は開始の 14 日前（11/17）だが、その日は過ぎている。**イベントが承認されたら 11/28 0:00**（月末の 3 日間＝「#11月読了本」の投稿と同じ日）。11/28 までに承認されなければ、承認された日。
- **優先度：通常**。1 月を高にする（同じ時期に並んだとき 1 月を前に）。
- **目的：すべてのユーザーに適切**。今年読み終えた本を、12 月に本棚へ「読了」で入れれば新しく入れた人も作れる（読了日が今年になる）ので、新規にも既存にも向く。
- **ディープリンク：なし（アプリを開くだけ）**。下の「ディープリンク」を見る。

### 画像・動画（文字は重ねない＝アプリが作った画像の中の文字だけ）
- **作り方**：`npm run demo` → `node scripts/share-images.mjs ui-shots/event-2026-12 year-`（今年の 1 枚を 重ね方 × 形 × 地 で書き出す・見本の 7 冊・2026.12.3）。
- **イベントカード 1920×1080（16:9）**：`year-record-post-paper`（書名と数字・投稿 4:5・紙）を真ん中に縦いっぱい（高さ 1080 に合わせる）で置き、左右は同じ紙の地の色で延ばす。下の 3 分の 1 にはイベント名とバッジが重なるので、画像の大事な所（「2026年の読書」の見出しと数字）は上と真ん中に。
- **詳細ページ 1080×1920（9:16）**：`year-record-story-paper` をそのまま（ストーリーの形は 9:16）。暗い背景が良ければ `year-record-story-night`。
- 使わないもの：重ね方「心に残った一文」（`year-quote-*`）は見本の本の著者の名前が入るので使わない。出版社の表紙の画像・著者の写真・端末の枠・宣伝の文字（「無料」など）は入れない。
- 動画（任意・30 秒まで）は作らない。

## 2. 1 月「今年こそ、読んで終わりにしない」

### 参照名（64 字まで）
```
2027-01 新しい年の読書計画
```

### イベント名（30 字まで・15 字）
```
今年こそ、読んで終わりにしない
```

### 短い説明（50 字まで・24 字）
```
1年後の目標から逆算して、読む本の順番を決める。
```

### 長い説明（120 字まで・88 字）
```
1年後の目標を書き「達成するには？」に答えると、読む本の順番が1本の道のりに。1日に読む時間を選ぶと、読書計画がカレンダーに。読む前は「この本で学べること」で中身をつかめます。
```

### 設定
- **バッジ：Special Event**。新しい年の読書計画という季節の行事。Challenge は、アプリに「期限までに達成」の仕組み（%・あと N 冊・遅れ）を作らない決まり（GLOSSARY の目標の行）なので使わない。
- **期間**：2027-01-01 0:00 〜 2027-01-31 23:59（日本時間・31 日）。
- **宣伝の開始**：2026-12-18 0:00（開始の 14 日前＝上限）。12 月のイベントと 12/18〜12/31 は並んで出る。
- **優先度：高**。「今年こそ読む・成長する」人がいちばん多い月（戦略 §5）。
- **目的：新規ユーザーを獲得**（入口 A＝成長したい・B＝読まなきゃ・戦略 §2）。
- **ディープリンク：なし（アプリを開くだけ）**。目標の画面は 振り返り › 行動 のいちばん上の行（`GoalEntry.jsx`）とホームの「目標を書く」から開く。

### 画像・動画
- **作り方**：`npm run demo` → `/?goals=on`（目標とロードマップがある見本）で撮る。
- **イベントカード 1920×1080**：ロードマップの「いまの 3 か月 · 1〜3 か月目」の枠（取り組むこと・おすすめの本・「本棚に入れる」）を、上の行と下のタブを切り落とした画面の部分だけで真ん中に。左右はアプリの地の色（明るい設定の `--bg`）で延ばす。
- **詳細ページ 1080×1920**：読書計画のカレンダー（「1 日に読む時間」の選ぶ所・「今日の本」の面・カレンダー）の 1 画面。
- 画面の中の文字はアプリのもの。足す文字・矢印・端末の枠は入れない。本の表紙が映るときは、見本の本の表紙がアプリの代わりの表紙か書店の画像かを見て、気になるなら表紙の映らない範囲で切る。
- 動画（任意）は作らない（`goal-roadmap` の録画には字幕が焼き込んであるため・Apple は文字の少ない絵をすすめている）。

## 3. ディープリンク（2 つとも「なし（アプリを開くだけ）」）

- アプリの中に URL の引数で画面を開く仕組みはある：`/?tab=review&sub=action`（振り返り › 行動）・`/?book=…&memo=…`（思い出しの通知）＝`src/App.jsx` の `handleRecallDeepLink`。ただし**通知から開いたときのアプリの中の行き先**で、外から開く入口が無い。
- iPhone のアプリに外からの URL を受ける設定が無い：`ios/App/App/Info.plist` に `CFBundleURLTypes`（独自のスキーム）が無く、`ios/App/App/App.entitlements` に Associated Domains（ユニバーサルリンク）が無く、`appUrlOpen` を受ける処理も無い（2026-11-23 に確かめた）。
- `&share=chooser`（写真で共有の選ぶシート）・`&goals=on`（目標の見本）・`&today=` はお試しモードだけ（`isDemo`）で、本番では効かない。
- だから空欄にする。イベントを押した人はアプリのホームが開く（12 月はホームに「2026年の読書を、1 枚の画像に」の 1 行が出る＝今年読み終えた本が 1 冊以上ある人だけ・`pickShareNudge`）。
- 次の版でディープリンクを付けるなら、ユニバーサルリンク（`orime.vercel.app` の `apple-app-site-association`）＋`appUrlOpen` で、12 月は写真で共有の「今年」、1 月は目標の画面を開く形。いまは作らない（この文書では提案だけ）。

## 5. 出す前の確かめ（App 内イベントの決まり）

1. **時期があること**：12 月は「今年」が 12 月だけ出るので時期そのもの。1 月は機能がいつでもあるので、文は「新しい年の読書計画」という季節に寄せた。通らなければ、1 月はイベントにせず、プロモーションテキスト（下の §6）だけにする。
2. **アプリの中で何をするかを書く**：2 つとも、押す所（写真で共有・「今年」／目標・「達成するには？」・1 日に読む時間・この本で学べること）を書いた。
3. **値段・無料・割引・創業メンバー価格・ほかのアプリの名前は書かない**（イベントの文と画像の両方。「今だけ」「期間限定」「お得」も使わない）。値段の案内はプロモーションテキストと SNS。
4. **言い切らない**：「変わる」「必ず」のような言い方は使わない。「作れます」「つかめます」まで。
5. **全員が文のとおりに使えるか**：12 月は条件（読み終えた本が 1 冊）を長い説明に書いた。1 月のロードマップとこの本で学べることは AI を使う（トークン）が、無料プランでもロードマップは 1 本つくれる・この本で学べることは約 2 トークン（`helpContent.js`）。文には量を書かない。
6. **画像**：1920×1080 と 1080×1920。画像の中に足す文字は入れない（イベント名とバッジは App Store が重ねる）。端末の枠・アプリのアイコンは入れない。
7. **審査**：イベントは 1 つずつ審査がある（覚えでは 1 日ほど）。12 月は**承認されたらすぐ**（11/28 に宣伝を始めるため）、1 月は 12/15 ごろまでに出す（12/18 の宣伝開始に間に合わせる）。ASO の Featuring Nomination（`company/aso-store-listing.md` §12）も 12 月中旬。

### 決まりの数で、覚えに自信が無いもの（App Store Connect の画面で確かめる）
- 字数（イベント名 30・短い説明 50・長い説明 120・参照名 64）・画像の大きさ（1920×1080・1080×1920）・期間の上限 31 日・宣伝は開始の 14 日前まで・バッジ 7 種・目的 4 種は、覚えのとおりに書いた。画面の入力欄の上限が違えば、短い説明と長い説明はそれに合わせて削る。
- 同時に出せるイベントの数（覚えでは承認済み 10・公開中 5）・審査の日数・公開前のアプリで作れるかは、確かでない。
- 時刻を日本時間で入れられるか（地域ごとの時刻か UTC か）は画面で確かめる。UTC なら 12 月の開始は 2026-11-30 15:00 UTC。
