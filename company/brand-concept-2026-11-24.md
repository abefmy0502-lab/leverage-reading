# orime のブランドの芯（2026-11-24・オーナーのロゴに込めた想いから）

> 正はここ。ロゴの形・色・素材の作り方は `DESIGN.md`（ロゴの決まり）と `scripts/brand-assets.mjs`。
> 売り場（LP・ストア・SNS）の言葉の正は今までどおり `company/lp-axis-2026-11-15.md`（「読んだ本と、会話できる。答えのもとは、あなたが残したメモ。」）。この文書はその奥にある「なぜ」を持つ。

## 1. ひとことで

**知識が重なり、答えが生まれる。**
Knowledge connects. New answers emerge.

このロゴは知識そのものを描いていない。知識が重なった結果として生まれる「まだどこにもなかった答え」＝まん中の余白を描いている。**いちばん大切にするのは中央の余白。**

## 2. ロゴの 3 つの意味

| 形 | 意味 |
|---|---|
| 2 本の帯（明るい茶・深い茶） | 異なる知識・経験・視点。それぞれが独立したまま、重なってひとつの形になる |
| 中央のひし形の余白 | 重なりから生まれる、自分だけの答え。誰かに与えられた答えではない |
| 循環するような形 | 学びは一度で終わらない。読む → 考える → 気づく → また出会う |

- 色は温かいブラウン（冷たいテクノロジーではなく、人のぬくもりのある知性）。
- 文字は小文字の「orime」（柔らかく親しみやすく、記号と一体に見せる）。サービス名はどこでも小文字（CLAUDE.md の GLOSSARY）。

## 3. ブランドの言葉（使うときはこの形）

```
orime
知識が重なり、答えが生まれる。

ひとつの知識は、それだけでは点にすぎない。
異なる知識が出会い、自分の経験と結びついたとき、
まだどこにもなかった答えが生まれる。

orime は、読んだことを残し、つなぎ、
自分だけの答えを見つける場所。

Knowledge connects. New answers emerge.
```

（オーナーの原案から、決まり文句の 1 行「学ぶことを、もっと自分らしく。知ることを、新しい可能性へ。」を外し、文を短く分けた。表記は小文字の orime にそろえた）

## 4. 製品とのつながり（ここがぶれないように）

ロゴの「答え」は、アプリの中では **相談の答え** のこと。
- 相談の答えは、本人が残したメモ（＝重なり合う知識）から生まれる。根拠のメモは「根拠を見る」で確かめられる。
- 別々の本のメモがつながる（本と本がつながる・ほかの本の視点で）＝「異なる知識の出会い」。
- 答えのあとに明日の一歩を決める（行動）＝答えが人生や仕事の中で働く。

つまり **ブランドの芯「知識が重なり、答えが生まれる」** と **売り場の言葉「読んだ本と、会話できる。答えのもとは、あなたが残したメモ。」** は同じことの表と裏。売り場では具体（会話・メモ）を先に、芯は奥で支える。

## 5. どこで使うか

| 場所 | 使い方 |
|---|---|
| LP | ヒーローは今の売り場の言葉のまま。下の方（例: 料金の前か最後の案内）にロゴと「知識が重なり、答えが生まれる。」の 1 行を置く案（入れるときは採点を通す） |
| note | 連載の「orime を作った理由」・ロゴを変えた話の記事に、§2 と §3 |
| プレスリリース・紹介資料 | 冒頭のロゴの下に §1、会社・サービス紹介に §3 |
| SNS | ロゴを変えた日の投稿に §2 の 3 つの意味（画像は横組みのロゴ） |
| アプリの中 | 出さない（画面は使い方に集中する）。設定 › アプリ・サポートなどに置くなら 1 行だけ |
| App Store | 説明文の最後の締めは今のまま。ブランドの言葉は入れない（検索と具体を優先） |

## 6. 書くときの決まり

- 「知識が重なる」「答えが生まれる」と言い切ってよいが、**効果を約束しない**（「必ず答えが見つかる」「人生が変わる」と書かない）。
- 「自分だけの答え」の主語は本人。AI が答えを作る、とは書かない（答えのもとは本人のメモ）。
- 英語の一文は添え書きとしてだけ使う（見出しにしない・全大文字にしない）。
