# 📚 これまで読んだ本で、相談相手をつくる（初日クイックスタート）— 設計案

> 2026-09-26 起案・**同日オーナー承認（3 点ともおすすめ案）→ 実装済み**（`src/components/PastBooksQuickstart.jsx`）。一番の価値「読むほど、自分だけの相談相手が育つ」（CLAUDE.md）を **初日に体験させる** ための機能。

## なぜ必要か

- 相談の答えは「あなたのメモ」が根拠。**入れたばかりの人はメモが 0 件なので、相談しても何も返せない**（今の最大の壁）。
- 今の初回の流れは「いま読んでいる本を 1 冊追加 → 読みながらメモ」。相談できる状態になるまで **数日〜数週間** かかり、その前に離脱する。
- でも多くの人は **すでに何冊も本を読んでいて、頭の中に「覚えていること」がある**。それを 5 分で入れてもらえば、初日から「複数の本をつなげた答え」が返せる。

## 流れ（4 画面・目標 5 分）

### ① 入口
- 初回ガイド最後の画面の主ボタンを **「これまで読んだ本から始める」** に（2 番目に「いま読んでいる本を追加」、3 番目に「AI に選んでもらう」）。
- 本棚の「はじめの一歩」と、ホームの相談カード（メモ 0 件の時）からも入れる。

### ② 印象に残っている本を選ぶ（3〜5 冊）
- 見出し：「これまで読んで、印象に残っている本は？」
- 検索欄で書名を入れて、選ぶだけ。選んだ本は下にチップで並ぶ（×で外せる）。
- 3 冊選ぶと「次へ」が押せる（5 冊まで。それ以上はあとで追加できる）。
- 状態は自動で「読了」。

### ③ 1 冊ずつ、覚えていることを一言
- 1 冊 1 画面（カードを横にめくる）：「『◯◯』で、いちばん覚えていることは？」
- 一行入力（例：「やらないことを決めるのが一番大事な仕事」）。
- **「思い出せない」でスキップ可**（責めない）。スキップした本は本棚には入るが、メモは無し。
- 入力した一言は、その本のメモ（カード式）として保存。

### ④ 相談相手ができた → その場で最初の相談
- 「あなたの相談相手ができました：5 冊・4 メモから答えます」
- すぐ下に **入力済みの相談例** を 2 つ出す（入れた本から自動で作る。例：「『エッセンシャル思考』と『人を動かす』から、いまの仕事で意識できることは？」）。
- タップすると相談タブへ移って、**複数の本をつなげた答え** が返る ＝ 初日の aha。
- 「はじめの一歩」の本・メモ・相談の 3 つが一気に埋まる。

## 作るもの（見積もり）

| 項目 | 内容 | 規模 |
|---|---|---|
| 新画面 `PastBooksQuickstart.jsx` | ②〜④ の全画面シート。本の検索は既存の `bookSearch`、保存は既存の `useBooks` / `useBookMemos` を再利用 | 中 |
| 入口の追加 | 初回ガイド最後・はじめの一歩・相談カード（メモ 0 件時） | 小 |
| 相談例の自動生成 | 入れた本の書名から 2 つ作る（AI は使わない＝原価ゼロ） | 小 |
| 計測 | `quickstart_started` / `quickstart_completed`（冊数・メモ数）/ その後の初回相談 | 小 |
| DB 変更 | **なし**（既存の books / book_memos にそのまま入る） | — |

お試しモード（`npm run demo -- ?demo=new`）で、画面を撮りながら作って確認できる。

## 決めてほしいこと

1. **冊数**：最低 3 冊・最大 5 冊（おすすめ）／最低 1 冊から OK にする
2. **置き場所**：初回ガイド最後の主ボタンにする（おすすめ）／あくまで任意の入口だけにする
3. **一言の入力**：スキップ可（おすすめ・責めない）／1 冊以上は必須にする

## やらないこと（今回）

- 読書メーター・ブクログ等からのインポート（外部連携は審査・規約の確認が必要なので別途）
- AI による「覚えていること」の自動補完（本人の言葉でないと、答えの根拠として弱くなるため）
