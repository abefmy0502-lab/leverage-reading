## 守ること
- **公開しない**。記事は「下書き保存」だけ。公開・予約投稿のボタンは押さない。
- **お金のかかるものは申し込まない**（note プレミアム・メンバーシップ・有料記事の設定・広告）。出てきたら閉じる。
- **パスワード・メールアドレス・電話番号・振込先には触らない**。
- **note ID（URL の note.com/〇〇 の部分）は変えない**（変えるかは私が決める）。
- 記事の中の【 】は**私にしか書けない事実**。埋めない・作らない・消さない。
- 画像のファイルを選ぶ場面では止まって、「◯◯ を選んでください」と私に伝え、私の「できた」を待つ。
- 迷う・エラーが出たら、画面の状態を伝えて聞く。各ステップの終わりに 1〜2 行で報告する。

   ```
   読書を、受け身から会話へ。
   読書メモから AI が本の語り口で答える読書アプリ「Orime（オリメ）」を、一人で作っています（作っている人：阿部文哉）。
   ```

## ステップ 3: 記事 04 を下書きに入れる（公開しない）
1. GitHub で `https://github.com/abefmy0502-lab/leverage-reading/blob/main/company/launch-2026-11/note-drafts/04-読書が受け身から会話に変わった話.md` →「Raw」を開く。
2. note →「投稿」→「テキスト」:
   - **題**: 本文の一番上の `# ` の行の文（`#` は付けない）
   - **見出し画像**: ここで止まる →「`note04-header.png` を選んでください」
   - **本文**: `# ` の題の行の次から最後まで。**ファイルの最初の「> 」で始まる注意書きと、題より前のメモは入れない**。
     - `## ` の行は note の「大見出し」、`### ` は「小見出し」にする（`#` の記号は残さない）。
     - `**…**` は太字にする（記号は残さない）。
     - 【 】と【画像：…】はそのまま残す。
     - `【LP のリンク（utm_campaign=note_dialogue）】` の所だけは、`https://orime.vercel.app/lp?utm_source=note&utm_medium=article&utm_campaign=note_dialogue` に置き換える（リンクにする）。
