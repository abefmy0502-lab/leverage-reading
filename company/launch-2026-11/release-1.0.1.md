## 3. Mac での作り方（`mac-build-prompt.md` の手順のまま・違うところだけ）

1. `git pull`（main の最新）。
2. 版を上げる（Xcode の「General → Identity」でも同じ）:
   ```bash
   sed -i '' 's/MARKETING_VERSION = 1.0.0;/MARKETING_VERSION = 1.0.1;/' ios/App/App.xcodeproj/project.pbxproj
   sed -i '' 's/CURRENT_PROJECT_VERSION = 9;/CURRENT_PROJECT_VERSION = 10;/' ios/App/App.xcodeproj/project.pbxproj
   npm version 1.0.1 --no-git-tag-version
   ```
   （1.0.0 の差し戻しでビルド番号を 10 以上に上げていたら、それより 1 つ大きい番号に）
3. `.env.production.local`（Mac・鍵の入ったほう）の `VITE_FOUNDING_OFFER_END` を **`2027-01-10`** に（Claude は中身に触らない）。`.env.production` はリポジトリで直してある。
4. `npm ci && npm run build && npx cap sync ios` → Xcode で Archive → App Store Connect へ上げる。
5. 上げたビルドを iPhone（TestFlight）で確かめる：
   - 有料プランの画面に「1 月 10 日まで」が出る（12/16 ではない）
   - 設定 → 利用規約に「公開から2027年1月10日(日本時間)まで」
   - 「読む」→ 計測で始めて 2 時間を超えた回をおわる → 「記録から外す」が出る（お試しでは `&focus=forgot`）
6. App Store Connect で 1.0.1 を作り、上の §2 を貼って、ビルドを選んで提出。リリースは「手動」。
7. 版の数を上げた `project.pbxproj` と `package.json` を Claude に渡せば、Claude がコミットして両方のブランチに push する（Mac ではコミットしない決まり）。
