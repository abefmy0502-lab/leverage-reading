## 3. Mac での作り方（`mac-build-prompt.md` の手順のまま・違うところだけ）

1. `git pull`（main の最新）。版の数（1.0.1・ビルド 10）は上がっている。**1.0.0 の差し戻しなどでビルド 10 以上をもう上げていたら**、Xcode の「General → Identity」の Build をそれより 1 つ大きい番号に。
2. `.env.production.local`（Mac・鍵の入ったほう）の `VITE_FOUNDING_OFFER_END` が **`2027-01-10`**、`VITE_SOCIAL=on` が残っていることを確かめる（Claude は中身に触らない）。`.env.production`（リポジトリ）は直してある。
3. `npm ci && npm run build && npx cap sync ios`（**cap sync を飛ばさない**＝画面の上下の直しはここで入る）→ Xcode で Archive → App Store Connect へ上げる。
4. 上げたビルドを iPhone（TestFlight）で確かめる：
   - **画面の上下に白い帯が無い**（設定 → 画面表示 → ダーク と ライト の両方で）：ホーム・相談・振り返り・本の詳細・設定・目標の画面・集中モード。状態バーの時刻がヘッダーに重ならない・下のタブの文字がホームバーに重ならない・上の余白が前より詰まっている（二重だった分）。相談で入力欄を押してキーボードを出したときも、入力欄がキーボードのすぐ上に来る
   - **ホーム画面のアイコン・起動画面・左上の印が新しいロゴ**（起動画面が古いままなら、アプリを消して入れ直す＝iPhone が起動画面を覚えているため）
   - 更新したあとに開くと「新しくなったこと」のシートが出る（ロゴ・本棚の形・この本を共有 の 3 件）
   - すべての本が本棚の形・本の「…」に「この本を共有」
   - 有料プランの画面に「1 月 10 日まで」が出る（12/16 ではない）
   - 設定 → 利用規約に「公開から2027年1月10日(日本時間)まで」
   - 「読む」→ 計測で始めて 2 時間を超えた回をおわる → 「記録から外す」が出る（お試しでは `&focus=forgot`）
5. App Store Connect で 1.0.1 を作り、上の §2 を貼る・§2-2 の説明文を貼る・ビルドを選んで提出。リリースは「手動」。
   - **スクリーンショット**：オーナーが作り直している画像が間に合えば、ここで差し替える（公開中の版の画像は新しい版の提出でしか変えられない）。間に合わなければ今の画像のまま出し、次の版（1.0.2）で差し替える＝1.0.1 は待たせない。
6. 何かを直した `project.pbxproj` などがあれば Claude に渡す（Mac ではコミットしない決まり）。
