### カスタムプロダクトページ（App Store Connect →「カスタムプロダクトページ」→ 作成）

| ページ | 画像（この順） | プロモーションテキスト（170 字以内） | キーワードの割り当て（キーワード欄の語から・1 語は 1 ページだけ） | 送り先のリンクに付ける ct |
|---|---|---|---|---|
| ① 乗り換え（ブクログ・読書メーターから） | `cpp-import-1`〜`3` | ブクログ・読書メーター・Kindle に残してきた記録を、書き出したファイルから取り込めます。取り込んだその日から、困ったことを相談すると、あなたの感想やメモを根拠に答えます。メモと相談は無料プラン（ずっと無料）で始められます。（114 字） | 本棚・感想・管理 | `note_import`・`x_import` |

### 作り直し方（画面を変えたら）

```bash
ln -s /path/to/本体/node_modules node_modules       # worktree のときだけ（終わったら rm node_modules）
VITE_DEMO=true npx vite --port 5198                  # 別のターミナル（npm run demo でも可・そのときは URL を 5173 に）
UI_SHOTS_URL=http://localhost:5198 node scripts/appstore-shots.mjs   # 撮る → 重ねる（30 枚）
```

- 撮った画面は `ui-shots/appstore-raw/`（git 管理外）。重ねる見た目と文言は `company/appstore-screenshots/index.html`。
- 撮影は `&lpshot=1` のお試しモード：相談の答えの相手が「2 冊の本と自分の学び」になり、実在の著者が話し手に見えない。写真から書き起こしの見本の文も、実在の本の一節に見えない短い文になる（`src/demo/demoFetch.js`）。
- 取り込みの見本のファイルは `scripts/fixtures/booklog-store.csv`（書名と自分の言葉の短いメモだけ）。
- Linux で撮るときは Noto Sans JP・Noto Serif JP を入れておく（無いと別の字体で出る）。
