## 3. 特定電子メール法のための確かめ（送る前に・オーナー）

| 表示すること | このメールでは | 確かめ |
|---|---|---|
| 送信者の氏名・名称 | 「Orime（運営 阿部文哉）」 | ✓ |
| 受信拒否の通知先（メールアドレスか URL） | orime.support@gmail.com への返信 | ✓（受けたら 3 営業日以内に `lp_waitlist` から消す） |
| 受信拒否の通知ができる旨 | 「配信の停止：…返信してください」 | ✓ |
| 送信者の住所 | **【住所】が空のまま** | ⚠ 要対応 |
| 苦情・問い合わせ先 | orime.support@gmail.com | ✓ |
| 同意の記録 | `lp_waitlist.created_at`（登録の日時）と、LP の欄の下の文言（使い道は公開のお知らせだけ） | ✓（送ったあと、消すまで残す） |

- **住所**：特商法の表記は「請求があれば開示」の運用だが、特定電子メール法では**送信者の住所を表示する必要がある**（本文に書くか、住所を書いたページへのリンクで示す）。自宅を出したくない場合は、バーチャルオフィス等の住所を用意する。決まるまで送らない。専門家（総務省・消費者庁の資料か、弁護士）に一度確かめると確実。
- 送り方：**宛先（To）・CC にアドレスを並べない**（BCC 一斉送信も事故が多いので避ける）。1 人 1 通で送れる配信の道具（例：Resend・Mailchimp・Gmail の差し込み）を使う。どれを使うかはオーナーが決める（無料枠で 1,000 通は足りる）。
- 送ったら：`update public.lp_waitlist set notified_at = now() where notified_at is null;`
- 配信停止・削除の返信が来たら：`delete from public.lp_waitlist where email = lower('…');`
- 公開から 3 か月以内（**2027-02-16 まで**）に全件を消す：`delete from public.lp_waitlist;`（カレンダーの 2/15 に入れた）
