# Chrome への指示（App Store Connect：ビルド 8 の準備・2026-11-22）

> 背景: ビルド 8（1.0.0・フォローあり）は App Store Connect にアップロード済み（2026-11-22 17:55）。本番の SQL も流し終えた（確かめる 4 つが true）。
> ここでは、パスワードの要らない App Store Connect の作業を Chrome に任せる。審査メモの差し替え（見本の ID が要る）は、見本のアカウントができてから別の指示文で。
> 使い方: 下の「ここから」〜「ここまで」を Chrome の Claude に貼る。

---ここから---

あなたは orime（読書メモのアプリ）の公開作業を手伝います。App Store Connect で、再提出の前の準備を 3 つします。

## 守ること
- 「審査内容を更新」「App Review に再提出」「審査へ提出」は押さないでください。
- パスワード・2 段階認証のコードは扱わないでください。ログインを求められたら止めて私に頼んでください。
- 下の 3 つ以外は変えない・消さない。値段（価格スケジュール）も変えないでください。
- 画面が手順と違う・迷うときは、止めて画面の文をそのまま報告してください。

## 作業 1：ビルド 8 をバージョン 1.0（1.0.0）に付ける
1. https://appstoreconnect.apple.com → アプリ → orime → 左の「iOS App」のバージョン 1.0 のページを開きます。
2. 「ビルド」の欄で、いま付いているビルド番号を報告してください。
3. 「ビルドを選択」（またはビルドの横の − で外してから ＋）で、**ビルド 8**（バージョン 1.0.0 (8)）を選んで「完了」→ ページ右上の「保存」。
   - ビルド 8 が一覧に無い・「処理中」のときは、何もせずにそう報告してください（Apple の処理に 10〜30 分かかります）。
   - 「輸出コンプライアンス」を聞かれたら、「暗号化を使っていない、または免除の対象（HTTPS だけ）」を選びます（Info.plist に免除の印が入っています）。

## 作業 2：月額・年額プランの配信の国を確かめる
1. アプリの「価格および配信状況」で、アプリが配信される国・地域の数を読みます（変えない）。
2. 「サブスクリプション」→「orime プラン」→「月額プラン」→「配信可否」（Availability）の国の数を読みます。「年額プラン」も同じく。
3. 月額・年額が**アプリと同じ数**なら何も変えずに報告。少ないときだけ、アプリと同じすべての国・地域を選んで保存し、変えたあとの数を報告してください。

## 作業 3：年齢区分の質問を見直す
アプリに「フォロー」が入りました（相手の ID かリンクでフォローを申し込み、相手が承認すると、その人の本棚＝書名・表紙・評価と「この本のまとめ」が見られる。メッセージ・チャットは無い。通報とブロックがある。名前で人を探す機能は無い）。
1. アプリ情報 →「年齢区分」の「編集」を開きます。
2. いまの答えと、いまの区分（例 9+ / 12+）をそのまま報告してください。
3. 次のように答えを合わせます（ほかの質問は変えない）:
   - 利用者が作るコンテンツ（User-Generated Content）に当たる質問：**はい**（ほかの利用者の本棚とまとめを見られる）
   - メッセージ・チャット（Messaging and Chat）：**いいえ**
   - 「通報やブロックなどの仕組みがあるか」を聞かれたら：**はい**
   - 位置情報の共有・出会い・ギャンブル・暴力などは：いいえ（今までどおり）
4. 保存したあとの区分を報告してください（変わったら、どう変わったかも）。

## 報告
- 作業 1：もとのビルド番号・ビルド 8 を付けられたか（処理中なら、その旨）
- 作業 2：アプリ・月額・年額の国の数（変えたなら前と後）
- 作業 3：もとの答えと区分・変えた答え・保存後の区分
