## 3. 設定（作るときに）

| 項目 | 設定 | 理由 |
|---|---|---|
| 参加の方法 | **参加コードを入力**（コードは創業メンバーにだけメールで送る） | 承認制だと一人ずつ確かめる手間が大きい。コードが外に出ても困るものは無い |
| 検索に表示 | オフ | 創業メンバーだけの部屋にするため |
| プロフィール | 部屋ごとのニックネーム（LINE の名前は出ない） | 会社員が気軽に入れる |
| 管理人 | 阿部文哉（本人の写真・名前） | 顔と名前を出す方針 |
| 共同管理者 | なし（当面） | |
| メッセージの送信 | 全員 | |

参加コードの渡し方：
- `launch-founding-offer.md` §4 の SQL で、**その週に新しくプランを始めた方**を出し、メールで 1 人 1 通（宛先を並べない）。最初は 11/20（金）、そのあとは毎週月曜（最後は 12/21（月）＝期間の終わりまでに始めた方の分）。
- メールは契約した方への特典のお知らせ（宣伝ではない）。それでも送信者名（Orime・運営 阿部文哉）・問い合わせ先・「今後この種のお知らせが不要な方は返信で」を入れる。

## 4. 最初の挨拶（部屋を開いたときに、ノートに固定する）

```
はじめまして、Orime を作っている阿部文哉です。
創業メンバーの部屋に来てくださって、ありがとうございます。

Orime は「読むほど、自分だけの相談相手が育つ」読書アプリです。
公開したばかりで、分かりにくいところも、足りないところもたくさんあります。

この部屋では、
・使っていて困ったこと、こうだったらいいのに、を気軽に書いてください。できるだけその日のうちに読みます
・毎週月曜に「次に作るもの」の投票を出します。木曜の夜に締めて、金曜に結果と作る予定をここと X でお伝えします
・作っている途中の画面も、先にここで見せます

いただいた声で直したものは、アプリの 設定 →「新しくなったこと」にも書いています。
これから、よろしくお願いします。
```

## 5. 部屋のルール（ノートに固定）

```
創業メンバーの部屋のルール

1. 個人が分かる情報（本名・メール・電話・会社名・メモの中身）は書かない
2. 宣伝・勧誘・ほかのサービスへの誘導はしない
3. ほかの方の投稿を、本人の許可なく部屋の外（SNS など）に出さない
4. 意見が違っても、相手を責めない
5. 開発者からの返事は、平日の夜と週末が中心です。急ぎの不具合は アプリの「フィードバック・要望を送る」へ

守られないときは、管理人が投稿を消したり、退出をお願いしたりすることがあります。
```

## 6. 投票のやり方（毎週）

| 曜日 | やること | 担当 |
|---|---|---|
| 金〜日 | 候補を 3〜5 個に絞る（部屋の声・フィードバック・運営ダッシュボードの「はじめての相談」の数字から） | オーナー（候補の整理は Claude） |
| 月 20 時 | LINE の「投票」で出す（1 人 1 票・匿名・締め切りは木曜 21 時） | オーナー |
| 木 21 時 | 締める | 自動 |
| 金 | 結果と「いつ・どう作るか」を部屋に書く → X に投稿（`x-posts.md` の P6 の型） | オーナー |
| 翌週〜 | 作る途中の画面を部屋で先に見せる → 出したら「新しくなったこと」に書く | Claude が作る／オーナーが見せる |

投票の文（例）：

```
【今週の投票】次に作るもの（木曜 21 時まで・1 人 1 票）

① 【候補 1：例「相談の答えを、そのまま行動リストに入れる前に直せるようにする」】
② 【候補 2】
③ 【候補 3】
④ その他（コメントで教えてください）

1 位になったものから作ります。1 位でも、すぐに作れないものは理由をお伝えします。
```

決まり：
- **候補は「作れるもの」だけ**にする（1〜2 週間で出せる大きさ。出せない約束をしない）。
- 1 位を作れない事情（審査・法令・原価）が分かったら、隠さずに理由を書く。
- 投票の結果を「◯人が選んだ」と外で言うときは、実数で（丸めない）。
- 部屋の投票に参加したことの見返りに、X への投稿やレビューを頼まない。メンバーが自分から Orime のことを投稿するときに、こちらから頼むことがあれば「創業メンバーとして参加している」ことを書いてもらう（特典を受けている関係を示すため・ステマ規制）。
