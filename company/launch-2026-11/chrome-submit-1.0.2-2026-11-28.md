# Chrome の Claude に貼る指示文：1.0.2 の申請（2026-11-28）

> 使い方：下の「ここから」〜「ここまで」を Chrome の Claude にそのまま貼る。
> 前提：Mac で 1.0.2 (11) を App Store Connect に上げてあること（`submit-1.0.2-2026-11-28.md` の A）。まだなら、作業 1 で「ビルドがまだ」と報告して止まる。
> 「審査に提出」は最後に必ず止まって聞く（オーナーが「はい」と答えたときだけ押す）。

---ここから---

あなたは orime（読書メモのアプリ）の App Store の申請を手伝います。App Store Connect で、バージョン 1.0.2 の文とビルドを入れて、審査に出す直前まで進めます。

守ること：
- パスワード・確認コードは入力も表示もしないでください。ログインや 2 段階の確認を求められたら、止めて私に頼んでください。
- 書いてある操作以外はしないでください。消す・取り下げる操作は、私に聞いてからにしてください。
- **「審査用に追加」「審査に提出」「このバージョンをリリース」は、押す直前に必ず止まって「押してよいですか？」と聞いてください。** 私が「はい」と答えるまで押さないでください。
- エラーや見慣れない表示が出たら続けず、その文をそのまま報告してください。

作業 0：今の状態を見る（読むだけ）
1. App Store Connect →「アプリ」→ orime を開きます。
2. 左の「iOS App」の下に並ぶバージョンと、それぞれの状態（例：配信準備完了・App Store で配信中・審査待ち・審査中・デベロッパのリリース待ち・提出準備中）を控えます。
3. 状態ごとに次のとおり進めます。
   - 1.0.1 が「App Store で配信中」（または「配信準備完了」）→ 作業 1 へ。
   - 1.0.1 が「デベロッパのリリース待ち」（承認済み）→ 止まって「1.0.1 をリリースしてよいですか？」と聞いてください。「はい」なら 1.0.1 の画面の「このバージョンをリリース」を押し、配信中になってから作業 1 へ。
   - 1.0.1 が「審査待ち」か「審査中」→ 止まって、その状態を報告してください（取り下げるかどうかは私が決めます）。
   - 1.0.2 がもう「提出準備中」で並んでいる → 作り直さず、それを開いて作業 2 へ。

作業 1：バージョン 1.0.2 を作る
1. 左の「iOS App」の横の「＋」（またはバージョンを追加）を押し、バージョン番号に **1.0.2** と入れて作ります。

作業 2：1.0.2 の中身を入れる
1. 「iOS App」の「1.0.2」を開きます。
2. 「このバージョンの新機能」に、下の【新機能】の囲みの中をそのまま貼ります。
3. 概要（説明文）・プロモーションテキスト・キーワード・サポート URL・スクリーンショットは**変えません**（前の版から引き継がれているはずです。空なら止めて報告）。
4. 「ビルド」の欄で **1.0.2 (11)** を選びます。
   - まだ出ていなければ「ビルドがまだ出ていません」と報告して止まってください（アップロードから 15〜30 分かかることがあります）。
   - 暗号化の質問が出たら「いいえ（使用していない）」を選びます（アプリに免除の設定が入っています）。
5. 「App Review に関する情報」の「メモ」で、先頭にある「1.0.1 の変更:」から始まる 3 行があれば消し、代わりに下の【審査メモに足す】の 4 行を先頭に入れます。それ以外のメモは消しません。デモアカウントの欄は変えません。
6. 「バージョンのリリース」は **「このバージョンを手動でリリースする」** を選びます。
7. 右上の「保存」を押します。

作業 3：アプリ内課金（読むだけ）
1. 「収益化」→「サブスクリプション」で、月額・年額の商品の状態を控えます（「承認済み」以外のものがあれば、その名前と状態）。
2. 「アプリ内課金」（追加トークンの 2 つ）も同じく状態を控えます。
3. 「審査待ちに追加が必要」などの表示があれば、何もせずに報告してください。

作業 4：申請の直前で止まる
1. 1.0.2 の画面の右上の「審査用に追加」（または「審査に提出」）の前で止まり、私に「押してよいですか？」と聞いてください。
2. 私が「はい」と答えたら押し、確かめの画面が出たら進めます（広告識別子の質問が出たら「いいえ」）。
3. 状態が「審査待ち」（Waiting for Review）になったことを控えます。

報告（最後にまとめて）：
- 作業 0 の各バージョンの状態
- 作業 2 で選んだビルド番号と、保存できたか
- 作業 3 で「承認済み」以外だった商品（無ければ「全部承認済み」）
- 作業 4 の状態
- エラーや見慣れない表示は文のまま

【新機能】
```
・相談で、本や著者と話せるようになりました。2 冊を選んで、考えをぶつけることもできます（答えは AI の解釈です）。
・家の本棚を撮ると、背表紙から何冊もまとめて本棚に入れられます。バーコードも続けて読み取れます。
・ブクログ・読書メーター・Kindle の記録を、もっとまとめて取り込めるようになりました。
・AI 選書を無料プランでも使えるようになり、AI の答えの回数も増えました。
・知識の地図で、読んできた本とメモのつながりを眺められます。どこまで読んだかの記録と、アーカイブも。
・お気に入りの著者の新しい本を、ホームでお知らせします。
・QR コードでフォローし合えるようになりました。ID は押すだけでコピーできます。
・言葉づかいと使い心地を全体に見直しました。
```

【審査メモに足す】
```
1.0.2 の変更: 相談に「本と話す」「著者と話す」を加えました。答えはどれも「AI の解釈で、著者本人の言葉ではありません」と画面に明記し、本人として名乗りません。
「本棚の写真からまとめて追加」とフォローの QR コードの読み取りでカメラを使います（写真は書名を読むためだけに AI へ送り、保存しません。AI に送る前に同意を確認します）。
思い出しと行動の期限の知らせは、端末の中だけの通知です（オンにしたときだけ・サーバーから送りません）。
デモアカウントは前回と同じです（課金済みの状態）。
```
