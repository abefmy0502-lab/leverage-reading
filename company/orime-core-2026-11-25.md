## 1. コンセプト（判断の基準）

- **orime は記録の置き場ではなく、重なりから自分の答えが生まれる場所。** 本の知識 × 自分の経験・過去の考え・別の分野・自分の問い・行動。
- **AI は答えを出さない。** 材料（本人の記録）を並べ、共通点・違い・問いを渡すまで。結論は本人が自分の言葉で書く。
- **一番の価値（CLAUDE.md）とつながる。** 自分の答えは「学び」として残り、相談の材料になる＝重なるほど相談相手が育つ。
- 競わせない（冊数・%・順位・連続日数は作らない）。記録を目的にしない。無料を不便にしない。

## 2. いまの orime にあるもの・足りないもの

| 指示書の機能 | いま | 足りないこと |

| 軽いメモ | ✅ メモを書く（1 タップ）・写真から書き起こし | — |
| 本以外の経験・気づき | ✅ 相談の「…」→「学びを書く」 | **入口が奥にある**（Phase 1b） |
| 関連する過去メモの自動提示 | ✅ つながるメモ（本と本・端末の中・2 字組の似ている度合い） | 本 × 学び（経験）を出していなかった → **今回** |
| 2 つの知識を結びつける（重なり） | ❌ | **今回の MVP** |
| 読後の問い | ✅ 読了の 3 つの問い（14 日） | — |
| 行動・実践の記録 | ✅ 行動（期限・完了・ふりかえり） | 結果の記録（Phase 2） |
| 忘れた頃の再提示 | ✅ 思い出しカード・思い出しの通知 | 「いまの悩み」と結びつけた再提示（Phase 2） |
| 問いの種 | ❌ | Phase 2 |
| 考えの変化（軌跡） | △ 読む前に書いたこと ↔ 読んだ後（読了 14 日） | Phase 2 |

画面の名前は日本語にする（指示書の ORIME CORE / SEED / TRACE は社内の呼び名。全大文字の英語の小見出しは作らない＝`/frontend-design`）:
**重なり**・**問いの種**・**考えの変化**・**自分の答え**・**行動**（いまのまま）。

## 4. 利用シーン

1. **読んで書いた直後**: メモを保存 →「いま書いたメモと似たメモ」→「重ねて考える」。
2. **いつでも自分で**: 本の詳細のメモの「…」→「重ねて考える」→ 重ねる相手を選ぶ（言葉・書名で探す）。
3. **仕事のあとに経験を書いた**（Phase 1b）: 学びを書く → 本のメモと重なる。
4. **迷ったとき**: 相談すると、残した自分の答えも根拠になる（今日から）。

## 5. 核の流れ（今回作ったもの）

```
メモ（本の知識） ──┐
                    ├─ 重なりのシート ─ ①2 つを少し重ねて並べる（ロゴの 2 本の帯）
学び（経験）     ──┘                   ②重なって見えること（AI・任意）＝共通／違い／問い
                                        ③自分の答え（本人が書く）→ 学びとして保存（@重なり）
                                                                    → 相談の材料に
```

- 候補: `lib/overlap.js` の `overlapCandidates`（つながるメモの仕組みに学びを足し、少し低い所から拾う・重なりの答えと AI のまとめは除く）。似た記録が無ければ、はじめから「重ねる相手を選ぶ」。
- AI: purpose `overlap`（Claude Haiku 5.5・出力 400 まで・無料プランも無料のトークンから）。材料は 2 つの文だけ。結論・行動の指示・一般論は書かない（`prompts.overlap`）。
- 保存: `book_memos` に学び（`book_id` なし・`source_type 'personal'`・タグ `@重なり`）。頭に「重なり：『A』のメモ × あなたの学び」の 1 行。新しい表なし。
- 同じ 2 つを何度もすすめないための印は端末に（`orime.overlaps.v1`）。

## 6. MVP と、その先

**Phase 1（今回）**: 重なりのシート・本 × 学びの候補・メモの「…」と保存したあとの入口・AI の 3 行・自分の答えを学びとして保存。
**Phase 1b（次）**: 学び（経験）を書く入口をホームのメモを書くと並べる／学びを保存したあとにも重なりの候補／重なりの答えの一覧（振り返り › メモに「重なり」）。
**Phase 2**: 問いの種（問いだけを残す・関係する記録が増えたら再提示）／考えの変化（同じテーマの前の記録と今の記録を並べる・断定しない）／行動の結果（試した → どうなった）／いまの悩みと結びつけた再提示。
**Phase 3（有料の核）**: 意味でつながる自動の関連付け（AI・膨大な記録）／あなたの思考の一年（年のレポート）／知識地図（最初は「つながった記録の一覧」から）／思考のクセ。

やらないこと: AI の要約を主役にする・読書量を競わせる・無料を不便にする・AI が思考を断定する・機能を一度に増やす。
