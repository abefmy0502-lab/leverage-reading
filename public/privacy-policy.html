プライバシーポリシー

最終更新: 2026 年 4 月 26 日

「レバレッジ読書ログ」(以下「本サービス」) は、利用者の個人情報の取り扱いについて、本ポリシーに従って適切に保護します。

1. 取得する情報

  • メールアドレス、表示名（アカウント登録時）
  • 本のタイトル、著者、ステータス、評価、進捗、タグなど (ユーザーが入力)
  • メモテキスト、写真、ページ番号、まとめメモ (ユーザーが作成)
  • マイ読書脳との対話履歴 (ユーザーが質問・AI が回答)
  • サービス利用に伴う技術的情報 (IP アドレス、ブラウザ情報、エラーログ等)

2. 利用目的

  • 本サービスの機能提供 (本管理、メモ管理、振り返り、AI 機能)
  • ユーザーのリクエストに応じた AI による解析・選書・要約
  • サービスの不具合対応・改善
  • 不正利用の検出と対応

3. 第三者提供

以下のサービス・事業者にデータの一部を提供します:

  • Anthropic Claude API: AI 分析・要約・対話のため、メモ・質問内容を送信します。Anthropic は API 経由で受け取ったデータをモデル学習には使用しないことを公表しています。
  • Supabase: ホスティング・データベース・認証・ストレージのため、すべてのアカウントデータを保管します。
  • Vercel: アプリケーションのホスティング。
  • Google Books API / openBD: 本の検索・表紙画像取得のため、検索クエリを送信します。

上記以外の第三者には、法令に基づく場合またはユーザーの同意がある場合を除き提供しません。

4. データの保管期間

アカウントが有効な間は無期限に保管されます。アカウント削除時には、関連するすべてのデータ (本、メモ、写真、対話履歴) が削除されます。

5. 利用者の権利

  • アカウント設定からデータを JSON 形式でエクスポートできます。
  • アカウント設定からアカウントの削除をリクエストできます (関連データもすべて削除されます)。
  • 個別データの修正・削除はアプリ内で随時可能です。

6. Cookie / ローカルストレージ

本サービスは認証セッションの維持・ユーザー設定 (ヘルプ表示状態、メモモード等) の保存のため、ブラウザの localStorage / IndexedDB を使用します。トラッキング目的の Cookie は使用しません。

7. セキュリティ

通信は HTTPS で暗号化されます。データベースへのアクセスは Row Level Security により利用者本人のみに制限されます。本のメモに添付された写真は非公開ストレージに保管され、署名付き URL でのみ閲覧可能です。

8. 改定について

本ポリシーは予告なく改定される場合があります。重要な変更がある場合はアプリ内で通知します。

9. お問い合わせ

本ポリシーに関するお問い合わせは、サービス内のサポート窓口までご連絡ください。
