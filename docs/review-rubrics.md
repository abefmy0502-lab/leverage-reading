# レビューの採点表（見た目以外）

見た目（UI）は `ui-critic`（`.claude/agents/ui-critic.md`・DESIGN.md の 10 項目×2 点）で採点する。
ここには、それ以外の 3 つの観点の採点表を置く（2026-09-29 オーナー依頼「UI・UX・操作感・顧客のニーズ・使いやすさの全観点で 19 点以上」）。
どれも **10 項目 × 2 点 = 20 点**。2 = 問題なし／1 = 小さな引っかかり／0 = 明確な問題。オーナー基準は **全対象で 19 点以上**。
採点する人は実装した本人と別にする（サブエージェント）。根拠は「どの画面・どの操作で・何が起きたか」を具体的に書き、19 点未満は「ファイル:行＋直し方」を必ず添える。

## 1. 使いやすさ（UX・タスクの流れごと）

対象は画面ではなく **タスク**（例: 初めて使って最初の相談をする／本を足してメモを書く／答えを行動にして完了する）。

| # | 項目 | 2 点の条件 |
|---|---|---|
| 1 | 入口が分かる | 目的の操作の入口を、初めての人が迷わず 1 回で見つけられる |
| 2 | 手数が少ない | 目的までのタップ・入力が最小（寄り道・二度手間・同じ入力の繰り返しがない） |
| 3 | 今どこか分かる | いまの画面・状態・進み具合が常に分かる（読み込み中・保存済み・送信中） |
| 4 | 言葉が分かる | 画面の言葉が使う人の言葉（GLOSSARY どおり・専門用語や内部の言い方がない） |
| 5 | 間違えにくい | 押し間違い・入力ミスを起こしにくい（確認・既定値・押せない状態・入力の制限） |
| 6 | やり直せる | 失敗・取り消し・戻るが効く（元に戻す・下書きが消えない・エラーから回復できる） |
| 7 | 一貫している | 同じ操作は同じ見た目・同じ場所・同じ結果（画面をまたいでぶれない） |
| 8 | 覚えなくていい | 前の画面の内容を覚えていなくても進める（必要な情報がその場にある） |
| 9 | 終わりが分かる | 終わったこと・次にすることが分かる（完了の知らせ・次の一歩） |
| 10 | 困ったとき | 空・エラー・上限・通信なしで行き止まりにならない（次の一手が必ずある） |

## 2. 操作感（手触り・タスクの流れごと）

実際にお試しモード（`npm run demo`）を Playwright で操作して確かめる（時間は計る）。

| # | 項目 | 2 点の条件 |
|---|---|---|
| 1 | 反応の速さ | 押してから見た目が変わるまで 100ms 以内（押した感触が必ずある） |
| 2 | 待ち時間 | 1 秒を超える待ちには形の骨組み・段階の表示があり、体感が短い |
| 3 | 跳ねない | 読み込み後・送信後に画面の位置や高さが跳ねない（押そうとした所がずれない） |
| 4 | 動き | 画面・シートの出入りが自然（速すぎず遅すぎず・向きが意味と合う・動きを減らす設定を守る） |
| 5 | 押しやすさ | 押せる範囲 44 以上・親指の届く位置に主な操作・誤タップしにくい間隔 |
| 6 | 入力 | キーボード・変換中の Enter・入力欄の自動フォーカス・入力が消えない |
| 7 | 手応え | 大事な操作に知らせがある（トースト・ハプティクス・完了の印）が、うるさくない |
| 8 | ジェスチャー | スワイプ・長押し・引っぱって更新・端から戻るが期待どおりに効き、誤作動しない |
| 9 | スクロール | 長い一覧・会話が滑らか。新しい内容が見える位置に来る。固定の欄が内容を隠さない |
| 10 | 戻る | ‹・端スワイプ・ブラウザの戻るで、思った画面に戻る（書きかけは確認してから） |

## 3. 顧客のニーズ（価値・使う人ごと）

対象は **使う人の場面**（例: 読んだビジネス書を仕事に活かしたい 30〜40 代の会社員が、1 週目・1 か月目・無料のまま・プランを迷っている）。
CLAUDE.md の「一番の価値（読むほど、自分だけの相談相手が育つ）」と SPEC.md を物差しにする。

| # | 項目 | 2 点の条件 |
|---|---|---|
| 1 | 価値がすぐ伝わる | 初めて開いて 1 分以内に「何ができて自分に何の得か」が分かる |
| 2 | 最初の成果が早い | 初日に「自分のメモから答えが返ってくる」体験まで短い道で着ける |
| 3 | 困りごとに効く | 仕事の悩みに対して、自分の読書を根拠にした具体的な答えと次の一歩が出る |
| 4 | 積み重ねが見える | メモが増えるほど相談が良くなることが、画面の言葉と数字で分かる |
| 5 | 行動につながる | 答え → 行動 → 完了 → ふりかえりの輪が自然に回る |
| 6 | また来たくなる | 通知・思い出しカード・行動の期限など、戻ってくる理由がある（押しつけがましくない） |
| 7 | 手間に見合う | 記録の手間（本の追加・メモ・取り込み）が得られる価値より小さい |
| 8 | 信頼できる | 答えの根拠が見え、作り話をしない。データ・プライバシー・お金の扱いに不安がない |
| 9 | 料金が納得できる | 無料でできること・プランの価値・7 日間無料・トークンが分かりやすく、損した感じがない |
| 10 | 他にない | 読書記録アプリ・AI チャットにない、このアプリならではの良さがはっきりしている |
