# orime.jp への切り替え手順（はじめての人向け）

2026-09-26 決定：本番のドメインを `orime.jp` にする。目的は、旧名（leverage）を利用者に見せないこと。

## 先に知っておくこと
- **このままでは進められない作業が 1 つある**：手順 3（Supabase）は Supabase の管理画面へのログインが必要。いまは GitHub のアカウントの件でログインできないので、復旧してから行う。手順 1・2・4 は先に進めてよい。
- **一部の設定はコードの反映後に効く**：`VITE_SITE_URL`・`VITE_SUPPORT_EMAIL` を読むコードは、まだ作業ブランチにあって main（本番）には入っていない。環境変数は先に入れておいてよいが、表示が切り替わるのは作業ブランチを main に取り込んで再デプロイした後。
- 管理画面のボタン名は、サービスの更新で少し変わることがある。見つからないときは、近い名前のメニューを探す。
- 全体の目安：実際の作業は 1〜2 時間。設定が世界中に行き渡るまでの待ち時間が、長いと最大 1 日ほどかかる（多くは 1 時間以内）。

## 手順 1. orime.jp を買う（15〜30 分）

`.jp` は日本国内に住所がある人しか登録できない。国内のサービスで買う。以下は、利用者の多い「お名前.com」の例（ムームードメイン・Xserverドメインでも流れは同じ）。

1. お名前.com のサイトで `orime` と入力して検索し、`.jp` にチェックを入れる。
   - 表示されたら空いている（すでに取られていたら表示されない）。
2. 申し込みに進む。
   - **オプションはほぼ不要**：レンタルサーバー・メールプラン・SSL などのおすすめが出ても、すべて外してよい（サイトは Vercel、HTTPS も Vercel が無料で用意する）。
   - **自動更新は ON**：切れると、アプリの規約ページも確認メールのリンクも止まる。
   - **住所の公開について**：.jp は登録者の情報が Whois（誰でも見られる登録者台帳）に出ることがある。個人の住所や電話を出したくなければ、「Whois 情報公開代行（代理公開）」のような項目があれば選ぶ。
3. 支払いを済ませ、登録メールアドレスに届く確認メールのリンクを押す。
   - **これを忘れると、しばらくしてドメインが止まる**ことがある。
4. 費用の目安：.jp は年に数千円。1 年目は安くても、2 年目以降の更新料が上がることが多いので、申し込み画面の「更新料金」を確認しておく。

## 手順 2. Vercel につなぐ（作業 15 分＋待ち時間）

### 2-1. Vercel にドメインを登録する
1. Vercel にログインし、Orime のプロジェクトを開く。
2. 上のメニューの **Settings** → 左の **Domains** を開く。
3. **Add**（または Add Domain）を押し、`orime.jp` と入力して追加する。
   - 「`www.orime.jp` も追加して、`orime.jp` へ転送するか」と聞かれたら、それを選ぶ（おすすめ）。
4. 追加したドメインの横に **Invalid Configuration**（赤）と出て、DNS に入れる値が表示される。この画面は開いたままにする。
   - 例：`orime.jp` には **A レコード**（値 `76.76.21.21`）、`www` には **CNAME**（値 `cname.vercel-dns.com`）
   - **値は必ず、Vercel の画面に出ているものを使う**（プロジェクトごとに違う値が出ることがある）

### 2-2. ドメイン会社に DNS を入れる（お名前.com の例）
DNS は「このドメインのサイトはどこにあるか」を示す住所録。2-1 で Vercel が表示した値を、ここに書き写す。

1. お名前.com Navi にログインし、「ドメイン」→「DNS 設定」（「DNS レコード設定」）を開いて `orime.jp` を選ぶ。
   - ネームサーバーが、お名前.com 以外（レンタルサーバーなど）になっていると、ここで入れた値が効かない。「お名前.com のネームサーバーを使う」になっているか確認する。
2. 次の 2 行を追加する。

   | ホスト名 | TYPE | VALUE（値） |
   |---|---|---|
   | （空欄） | A | Vercel に出ている値（例 `76.76.21.21`） |
   | www | CNAME | Vercel に出ている値（例 `cname.vercel-dns.com`） |

   - ホスト名の空欄は `orime.jp` そのもの、`www` は `www.orime.jp` を表す。
   - 同じホスト名で A レコードがもう 1 行ある場合（初期設定の駐車ページ用など）は、それを消す。
3. 「確認画面へ進む」→「設定する」で保存する。

### 2-3. つながったか確かめる
1. Vercel の Domains の画面に戻る。数分〜1 時間ほどで **Valid Configuration**（青・緑）に変わる。
   - HTTPS の証明書は Vercel が自動で用意する。何もしなくてよい。
2. スマホや PC で `https://orime.jp` を開き、Orime の画面が出れば完了。
3. 旧アドレス `leverage-reading.vercel.app` も、そのまま動き続ける。古いリンクは切れない。

## 手順 3. Supabase の Site URL を変える（5 分・**Supabase にログインできるようになってから**）
アプリで新規登録したとき、確認メールのリンクはここで設定した URL に飛ぶ。変えないと旧アドレスに飛んでしまう。

1. Supabase にログインし、Orime のプロジェクトを開く。
2. 左の **Authentication** → **URL Configuration** を開く。
3. **Site URL** を `https://orime.jp` にして **Save**。
4. すぐ下の **Redirect URLs** で **Add URL** を押し、`https://orime.jp/**` を追加する。
   - 旧アドレス（`https://leverage-reading.vercel.app/**`）は、しばらく消さずに残す。
5. 同じ Authentication の **Email Templates** で、確認メールの本文を開く。旧名（レバレッジ など）やアドレスが直接書かれていれば、Orime に直す。

## 手順 4. 環境変数を入れて再デプロイ（10 分）
環境変数は「アプリに渡す設定値」。コードを書き換えずに値だけ差し替えられる。

1. Vercel のプロジェクト → **Settings** → **Environment Variables** を開く。
2. 次の 3 つを 1 つずつ追加する（Key に名前、Value に値。**Environment は Production にチェック**）。

   | Key | Value |
   |---|---|
   | `VITE_SITE_URL` | `https://orime.jp` |
   | `APP_ORIGIN` | `https://orime.jp` |
   | `RAKUTEN_APP_URL` | `https://orime.jp` |

   - 末尾に `/` を付けない。
   - `RAKUTEN_APP_URL` がすでにある場合は、⋯ → Edit で値を書き換える。
3. **楽天の管理画面**（楽天ウェブサービスのアプリ設定）で、「許可された Web サイト」に `https://orime.jp` を追加する。これが無いと、楽天から本の表紙が取れなくなる。
4. 環境変数は、入れただけでは反映されない。**再デプロイ**する：Vercel の **Deployments** → 一番上の Production の行の ⋯ → **Redeploy**。
   - `VITE_` で始まる値が表示に反映されるのは、作業ブランチを main に取り込んだ後（「先に知っておくこと」参照）。

## 手順 5. 問い合わせメール support@orime.jp を用意する（20〜30 分）
App Store の審査と特商法の表記で、問い合わせ先は必須。**受け取るだけなら、無料のメール転送で足りる**（support@orime.jp に届いたメールを、普段の Gmail に転送する）。

### 5-1. 無料の転送サービスを使う（例：ImprovMX）
1. ImprovMX のサイトで、転送先にしたい普段のメールアドレスを入れて登録し、`orime.jp` を追加する。
2. エイリアス（受け取る名前）に `support` を作り、転送先を普段のメールアドレスにする。
3. ImprovMX の画面に、DNS に入れる値が出る。手順 2-2 と同じお名前.com の DNS 設定画面で、次を追加する。

   | ホスト名 | TYPE | VALUE | 優先度 |
   |---|---|---|---|
   | （空欄） | MX | 画面の値（例 `mx1.improvmx.com`） | 10 |
   | （空欄） | MX | 画面の値（例 `mx2.improvmx.com`） | 20 |
   | （空欄） | TXT | 画面の値（例 `v=spf1 include:spf.improvmx.com ~all`） | — |

4. ImprovMX の画面ですべて緑（OK）になったら、別のアドレスから `support@orime.jp` にメールを送り、普段の受信箱に届くか確かめる。

### 5-2. `support@orime.jp` から返信もしたいとき
- 無料の転送だけでは、`support@orime.jp` を差出人にして送れない。
- 必要になったら、ImprovMX の有料プランや Google Workspace（月に数百〜千円程度）に切り替える。
- 最初は受信だけで十分。返信は普段のアドレスからでも問題ない。

### 5-3. アプリに反映する
1. Vercel の環境変数に `VITE_SUPPORT_EMAIL` = `support@orime.jp` を追加し、再デプロイする。
   - 手順 4 と同じ。作業ブランチを main に取り込んだ後に表示が切り替わる。
2. 設定画面・エラー画面・特商法ページのメールアドレスが、一斉に `support@orime.jp` になる。

## ついでにやること
- **Amazon アソシエイト**：アソシエイト・セントラル →「トラッキング ID の管理」で Orime 名の ID（例 `orime-22`）を追加し、環境変数 `VITE_AMAZON_TAG` に入れる。
- **App Store Connect**（審査の前に）：プライバシーポリシー URL `https://orime.jp/legal/privacy`、サポート URL `https://orime.jp/legal/sct`、マーケティング URL `https://orime.jp`。
  - 文面は `company/app-store-listing.md` にある。
- **Apple でサインイン**（Web で使う場合だけ）：Apple Developer の Service ID の Domains / Return URLs に `orime.jp` を追加する。
