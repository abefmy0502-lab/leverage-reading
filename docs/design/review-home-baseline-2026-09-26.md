## 直すべき点（重要な順）
1. ホームを SPEC §1 の 3 ブロック（相談／いま読んでいる本／すべての本 ›）に。検索・絞り込み等はライブラリ画面へ、思い出しカードは振り返りへ。主ボタンは相談の送信 1 つ
2. 12px 未満の文字を 12〜13 に。読む文章は明朝 18・行間 1.6。見出しは 20/600。太さは 400/600/700 のみ
3. 左右余白 16、カード内 16、カード間 24。gap は 4/8/12 に
4. 操作部品の枠を `--border`（3.6:1 以上）に
5. アクセントを栗色 `#8a4b2a` に。ステータス色と絵文字をやめる。押せない見出しは `--text-2`
6. 角丸 12 に統一、普通のカードの影をやめる、直書き色をトークンにして暗い画面の値を入れる
7. ヘッダーのボタンを 44×44 に

SPEC への提案：ヘッダーの挨拶（11px・数秒で消える）は、ホーム整理時に消すか画面タイトル「ホーム」に置き換える。
