## 1. 取得する情報

当方は、本サービスの提供にあたり、次の情報を取得します。

### (1) ユーザーが登録・入力する情報
- メールアドレス、認証情報（パスワード等。ハッシュ化等の処理は認証基盤事業者が行います）
- 本の情報（タイトル、著者、ISBN、ASIN、表紙画像、ステータス等）
- メモ・まとめ（テキスト）、タグ、ページ番号
- アップロードされた写真画像
- 行動リスト、振り返り、AIへの質問文・選書アドバイザーへの入力内容
- 本以外の学びログ、その他ユーザーが入力する一切のコンテンツ
- お問い合わせ・フィードバックの内容、氏名（任意）、連絡先（任意）

### (2) 課金・購読に関する情報
- 有料プランの契約状況、購読ステータス、課金履歴
- 各ストアのトランザクション識別子、購読開始日・更新日・有効期限等の購読状態情報（Apple App Store / Google Play でのアプリ内課金につき、購読状態管理サービス RevenueCat を通じて取得します）
- ※ クレジットカード番号等の決済情報は、Apple（App Store）または Google（Google Play）が直接取得・管理し、当方はこれを取得・保持しません。Web 版をご利用の場合は、決済代行事業者（Stripe）が PCI-DSS に準拠してこれを取得・管理し、当方はカード番号全体を保持しません。

### (3) 自動的に取得する情報
- 利用ログ、アクセス日時、エラー情報、利用環境（ブラウザ・OS 等の情報）
- Cookie 等によるセッション・認証維持のための識別情報
- 利用状況の記録（製品改善のため、当方自身のサーバーにのみ記録するファーストパーティの利用状況情報。記録されるのは「どの機能が、いつ、何回使われたか」といったイベント名と小さな区分値・回数のみで、メモ本文・書名・著者・検索語・自由入力等や個人を特定する内容は含めません。外部の解析サービスには送信せず、設定画面からいつでもオフにできます）

## 2. 利用目的

当方は、取得した情報を次の目的で利用します。

1. 本サービスの提供、本人認証、アカウント管理
2. ユーザーが登録したコンテンツの保存・表示・検索・バックアップ
3. AI機能（Q&A、要約、選書提案、分析等）の提供
4. 有料プランの課金、購読状態の管理、契約管理（アプリ内課金の購読ステータス確認を含みます）
5. お問い合わせ・フィードバックへの対応
6. 不正利用の防止、セキュリティの確保
7. 本サービスの維持・改善・新機能の開発
8. 重要なお知らせ・規約変更等の通知
9. 法令に基づく対応

当方は、利用目的の達成に必要な範囲を超えて個人情報を取り扱いません。

## 3. 第三者提供・業務委託

1. 当方は、法令で認められる場合を除き、あらかじめユーザーの同意を得ることなく、個人情報を第三者に提供しません。
2. 当方は、本サービスの提供に必要な範囲で、以下の事業者に個人データの取扱いを委託しています。当方は委託先に対し、適切な監督を行います。

3. AI機能を利用する場合、当該機能に関連するコンテンツ（メモ・本情報・質問文等）が AI 事業者の API に送信されます。AI機能をはじめて使うときに、送信する情報と送信先をアプリ内で示し、ユーザーの同意を得てから送信します（同意しない場合は送信しません。同意は設定の「AI へのデータ送信」からいつでも取り消せ、送信先を変更する場合は改めて同意を得ます）。送信される情報の範囲と送信先は、利用する機能により異なります（上の表）。各社の API の規約により、送信したデータは AI モデルの学習に使われません（Anthropic は API 経由のデータを学習に使いません。Google は有料の Gemini API のデータを製品の改善に使わず、当方は有料の API だけを使います）。各社は不正利用の監視等のため一定期間保存することがあります。

## 4. Cookie 等の利用

1. 本サービスは、ログインセッションの維持・認証・利便性向上のために Cookie および類似技術（ブラウザのローカルストレージ等）を使用します。
2. これらは本サービスの動作に必要なものであり、広告目的のトラッキングには使用しません。
3. ユーザーはブラウザの設定で Cookie を無効化できますが、その場合、ログイン等の一部機能が利用できなくなることがあります。
4. 本サービスは、改善・優先順位づけのため、本サービス内での操作にともなう利用状況を当方自身のサーバー（委託先 Supabase 上のデータベース）にのみ記録します（ファーストパーティの記録。第三者の解析・広告事業者へは送信しません）。記録するのは「どの機能が、いつ、何回使われたか」といったイベント名と小さな区分値・回数・真偽値に限られ、メモ本文・書名・著者・検索語・自由入力等や個人を直接特定する内容は記録しません。ユーザーは設定画面（⚙️ 設定 → 「📥 データ・アプリ」内の「📊 利用状況の記録」）からいつでもオフにできます。

## 5. 個人情報の保管・安全管理措置

1. 当方は、個人データの漏えい・滅失・毀損の防止その他の安全管理のために、必要かつ適切な措置を講じます。具体的には次のとおりです。
   - 通信の暗号化（HTTPS / TLS）
   - データベースの行レベルセキュリティ（RLS）による、ユーザーごとのアクセス制御
   - 写真等のファイルを非公開（private）バケットに保管し、署名付き URL による限定的なアクセス制御
   - 適切なアクセス権限管理、認証情報の保護
   - セキュリティヘッダー（CSP 等）による外部送信先のホワイトリスト制限
2. 当方は、利用目的の達成に必要な期間、または法令で定められた期間、個人情報を保管し、不要となった情報は適切に消去します。
3. 委託先（Supabase、Vercel、Anthropic、OpenAI、Apple、Google、RevenueCat、Stripe 等）における安全管理措置については、各社の定めるところによります。

## 6. 個人データの外国（国外）における取扱い

1. 本サービスは、Supabase、Vercel、Anthropic、Apple、Google、RevenueCat、Stripe 等のクラウドサービス・決済サービスを利用しており、ユーザーの個人データ（課金・購読状態に関する情報を含みます）が日本国外（米国等）のサーバーで保管・処理される場合があります。
2. AI機能の利用にあたり、入力されたコンテンツが Anthropic・Google の国外事業者の API に送信されることがあります。ユーザーのコンテンツを OpenAI に送信することはありません（OpenAI は、上の表のとおり運営者だけが使う運営の分析の補助に、集計した数字だけを送ります）。また、有料プランの課金・購読管理にあたり、購読状態に関する情報が Apple、Google、RevenueCat、Stripe 等の国外事業者に送信・保管されることがあります。
3. これらの外国にある第三者への提供にあたり、当方は個人情報保護法に基づき、当該事業者が継続的に適切な措置を講ずるよう必要な対応を行います。各事業者の所在国・体制等に関するお問い合わせは、本ポリシー末尾の窓口までご連絡ください。

## 7. 保有個人データの開示・訂正・利用停止等の請求

1. ユーザーは、当方が保有する自己の個人データについて、利用目的の通知、開示、内容の訂正・追加・削除、利用の停止・消去、第三者提供の停止を請求できます。
2. これらの請求は、本ポリシー末尾のお問い合わせ窓口にて受け付けます。当方は、本人確認を行ったうえで、法令に従い合理的な期間内に対応します。
3. ユーザーは、本サービス内の機能により、自己のデータを自身で閲覧・編集・削除（JSON 形式でのダウンロード、退会によるデータ削除リクエストを含む）することもできます。
4. 退会（アカウント削除リクエスト）時には、法令上保管が必要な情報を除き、関連データを合理的な期間内に削除します。
