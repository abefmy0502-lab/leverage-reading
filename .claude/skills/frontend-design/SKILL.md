# /frontend-design — 見た目を作るときの型（2026-10-31）

元: anthropics/skills の `frontend-design`（Apache 2.0）。Orime は見た目の軸の多くを **`DESIGN.md` が固定している**ので、ここでは「固定された軸」「自由な軸」「生成された画面の癖」「文の決まり」「手順」だけを持つ。

## 0. 固定された軸（変えない・DESIGN.md が正）
- 色: ニュートラル＋栗色（`--accent`）1 色＋状態色 3 色。暗い画面はトークンで自動。
- 文字: UI はゴシック（`--font-ui`）・読む文章と大見出しは明朝（`--font-read`）。大きさは `--text-*`・太さ 400/600/700。
- 余白 4/8/12/16/24/32/48/64・角丸 12 の 1 種類・影は面の明度差（暗い画面で影を使わない）。
- 部品は既存（`btnPrimary` / `btnGhost` / `btnLink` / `EmptyState` / `ErrorMessage` / `BottomSheet` / `SegThumb` …）。
- 言葉は GLOSSARY（CLAUDE.md）。ゲーミフィケーション（%・バッジ・連続日数・順位）は作らない。

> 「クリーム地＋明朝＋土色のアクセント」は生成された画面の癖の 1 番目でもある。Orime はこれを**決めて**使っている（ブランド）。だから、ほかの癖は 1 つも足さない。

## 1. 自由な軸（ここで差をつける）
- **何を主役にするか**（ヒーローは「その題材の世界でいちばん特徴的なもの」を、いちばん合う形で）。Orime なら「残した一行 → 本の語り口の答え」の実物。大きな数字＋小さなラベル＋グラデの帯は既定の型なので、本当に最適なときだけ。
- **構造の印は情報**（線・番号・見出しの飾りは「中身の構造」を表すときだけ）。番号は本当に順番があるもの（手順・時系列）だけ。
- **動きは 1 回の演出**（読み込み時の 1 回か、押した結果を見せる動き）。区画ごとの「ふわっと出る」・カードごとの hover は癖。
- **大胆さは 1 か所**。ほかは静かに。出す前に「飾りを 1 つ外す」。

## 2. 生成された画面の癖（出す前のチェック・1 つでもあれば直す）
- [ ] 見出しの 1 語だけを色・斜体・太字で目立たせている
- [ ] 小見出しが全大文字・字間を広げた英字（`READ. NOTE. GROW.` の類）
- [ ] 中身の上に、要らない小さなラベル（eyebrow）を置いている
- [ ] 順番のない並びに `01 / 02 / 03`
- [ ] 同じ角丸・同じ薄い影のカードが並ぶ「SaaS のカードの型」・飾りのグラデ
- [ ] 中黒でつないだメタ文字列（`A · B · C`）を飾りに使う（情報として必要なら可: 「p.33 · 10/23」）
- [ ] 「WORD — 断片」の形のラベル・`→` を文の最後に足したボタン・リンク
- [ ] 区画ごとの fade-and-slide の登場・全カードの hover の動き
- [ ] 小さなデータのラベルに等幅フォント
- [ ] 文: 謝るエラー（「申し訳ありません」）・曖昧なエラー（「エラーが発生しました」）・空の画面に気分だけ（「まだありません」で終わる）

## 3. 文の決まり（デザインの一部）
- 利用者の言葉で名前を付ける（仕組みの名前にしない）。説明は「何をするか」を平易に。売り文句にしない。
- ボタンは起きることを言う（「保存」ではなく「保存して読書を開始」）。同じ操作は流れの最初から最後まで同じ名前（「公開」→「公開しました」）。
- エラーは謝らず、何が起きたかと直し方を言う。空の画面は次の一歩への招待にする（`EmptyState` の `actions`）。
- 能動態・口語・飾りの語なし。1 つの文に 1 つの仕事。

## 4. 手順
1. **題材を 1 行で**（誰に・何の画面・いちばんの仕事）。CLAUDE.md の「一番の価値」に照らす。
2. **計画を 5 行で**（主役・構造の印・動きの 1 回・文の芯・大胆さを使う 1 か所）。
3. **癖の照合**: 「同じ依頼で、ほかのアプリでも同じ画面を作るか？」と自問し、§2 の癖に当たる所を直す。直した所と理由を書く。
4. **作る**（§0 の固定された軸・既存部品・トークンだけ）。CSS は型の選択子（`.section`）と要素の選択子（`.cta`）の打ち消し合いに注意。
5. **撮って見る**: `npm run demo` → `npm run ui:shots -- after <画面名>`（明暗）。自分で見て「飾りを 1 つ外す」。
6. **採点**: `ui-critic`（16/20 以上・§2 の癖は項目 5・6・10 で減点される）。
7. **文書**: `DESIGN.md` §5（新しい部品）・`SPEC.md`（画面の役割）・`releaseNotes.js`（ルール 5）。
8. `/ship`。
